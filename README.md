# 우리학교 블록월드

마인크래프트 느낌의 3D 가상 학교예요. 스마트폰 브라우저에서 바로 열리고, 학생은 회원가입 없이 QR 코드로 들어와요.

## 처음 올리기 (선생님만, 한 번)

1. github.com 가입 → 오른쪽 위 **+** → **New repository**
2. 이름 예: `school` / **Public** 선택 → **Create repository**
3. **uploading an existing file** 누르기 → 이 폴더의 파일 5개(`index.html`, `menu.txt`, `news.txt`, `settings.txt`, `README.md`)를 끌어다 놓기 → **Commit changes**
4. **Settings → Pages** → Branch를 `main` / `/(root)`로 고르고 **Save**
5. 1~2분 뒤 `https://아이디.github.io/school/` 주소가 생겨요. 이 주소로 QR 코드를 만들어 나눠 주세요.

## 매달 급식 바꾸기

1. 저장소에서 `menu.txt` 누르기 → 연필(✏️) 아이콘
2. 맨 위 `2026년 11월`을 새 달로 고치고, 학교 홈페이지 식단을 그대로 복사해 붙여 넣기
   - 날짜 줄(`1 일`, `12/1`, `2026-12-01` 모두 가능) 아래에 메뉴를 한 줄씩
   - 알레르기 숫자·`[채식급식의 날]` 같은 안내·아래쪽 알레르기 정보는 자동으로 지워져요
3. **Commit changes** → 1~2분 뒤 모든 학생 화면에 반영돼요 (주소와 QR은 그대로)

## 학교 소식 바꾸기

`news.txt`에서 한 줄에 하나씩 `제목 | 내용`으로 고치면 돼요.

## 건의함 연결하기

1. 구글 설문지를 만들고 "로그인 필요"를 끈 뒤 **보내기 → 링크** 주소를 복사
2. `settings.txt`의 `건의함주소:` 뒤에 붙여 넣기
3. 학생 건의는 선생님 구글 설문지 응답에서 볼 수 있어요

## 주의

- 주소를 아는 사람은 누구나 들어올 수 있어요. 학생 이름 같은 개인정보는 파일에 쓰지 마세요.
- 캐릭터와 도장은 학생 각자의 기기(브라우저)에 저장돼요.
- 게임을 고치고 싶으면 `index.html`을 새 파일로 다시 올리면 돼요.
